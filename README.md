# mods

Моды для Claude Code.

## cache-keeper

Полоса над полем ввода: `warm 42m | ctx 111k 55% | 5h 10% · week 59% | ≈$1.01 | in 1.2k out 340 cached 18k | RU 85%`.

- Показывает, сколько ещё тёплый кэш (`warm 42m` / `cache cold`), размер контекста, лимиты и расход сессии (`≈$` — по ценам API, для подписки это оценка, а не списание).
- `in/out/cached`: токены последнего хода (`in` = новые + записанные в кэш, `cached` = прочитанные из кэша), субагенты не считаются.
- `RU`: доля кириллицы среди букв в твоём последнем промпте.
- `H` (или `/handoff`): модель пишет записку о сессии, она сохраняется в `.cache-keeper/handoffs/`. Если `RU` от 50%, записка пишется по-русски (заголовки разделов остаются английскими, по ним находятся шаги для кнопок).
- Если рабочая папка — git-репозиторий (есть `.git`), мод дописывает `.cache-keeper/` в `.git/info/exclude` (локальный список исключений, в коммиты не попадает); если туда писать нельзя (например, worktree), — в `.gitignore`.
- `C` (или `/handoff continue`): очищает сессию (`/clear`) и продолжает по записке.
- Пункты «Pick up here» из записки становятся кнопками `1`–`3`: выбор очищает сессию и начинает с него.
- Подсказка «context is heavy» появляется, когда кэш остыл и контекст больше `warnPercent` окна, либо больше `urgentPercent` независимо от кэша.
- Строка под полосой (одна, самая важная; пропадает, когда записка уже сохранена):
  - `cache cools in 8m: press H now…` — за `soonMinutes` минут до остывания (если контекст от 20k токенов): записку дёшево сделать, пока кэш тёплый;
  - `cache is cold: your next message re-writes ~470k tokens` — кэш остыл, и вот сколько токенов придётся записать заново;
  - при тяжёлом контексте то же вместе с призывом «H, потом C».
- Цвета: контекст — жёлтый от `warnPercent`, красный от `urgentPercent`; лимиты `5h`/`week` — жёлтый от 70%, красный от 90%.

Настройки: `ttlMinutes` (60), `soonMinutes` (10), `warnPercent` (60), `urgentPercent` (80).

```
/plugin install cache-keeper --marketplace almunkonst/mods
```
